# InsectRoleVision
A computer vision system to study arthropod diversity and functional roles

The source code used to train and develop the model was listed with the file names "ScanBugM1" or "ScanBugS1/2" (ScanBug is the model's initial name). "M1" indicates multiclass annotation, while "S1/2" indicates single-class annotation. "S1" focuses on object localization, and "S2" focuses on classification.
